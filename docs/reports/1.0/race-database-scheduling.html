CI cleanup and federation deadline repairs

Two concrete fixes: isolate application database cleanup from peer migrations, and refuse federation responses whose bounded context expired during the final body read.

GitHub adapter PR #677 passed its real-provider acceptance, then hosted race CI exposed PostgreSQL fixture cleanup contention. The functional recovery assertions completed; the five-second database-drop cleanup expired while PostgreSQL synced a checkpoint.

Validation

The old inline invocation failed the scheduling regression; the new helper passed nine valid scope/failure combinations and 13 invalid inventory cases. Every assigned package executes once, app last and alone, and either group's failure fails the step. ShellCheck, Bash syntax, Actionlint and trusted-CI checks passed.

Five isolated repetitions of the actual dual-engine recovery test under the race detector passed: 25 named PASS events, zero skips, 152.645 seconds including compilation. This is real PostgreSQL/SQLite execution on unchanged app source at ee8924e6. It does not reproduce hosted I/O load or replace exact-head CI.

The scheduling change preserves production source, test deadlines and durability settings. The separate federation acceptance fix is described below. Handoff and exact evidence scope. CI prerequisite delivery and subsequent #677 validation remain the parent's next steps.

Federation deadline acceptance

Prerequisite source 877f37b9 exposed a core-test failure: a stalled federation body was accepted at deadline expiry. One hundred local repetitions of the existing TLS test passed; the precise hosted interleaving remains source-qualified.

ReadAll can return complete bytes and no error when its final read reports EOF during cancellation. The private response-buffering boundary now checks context state before publishing provider bytes and closes the original body on every outcome. Deterministic manual-cancel and actual-deadline EOF regressions were red before the check; a live-context control preserves the response.

Recommended choice: enforce cancellation at acceptance. Alternatives were retrying CI, increasing the timeout or weakening the assertion; those leave the defect. The production 15-second deadline, 100 ms TLS test deadline, byte ceilings and DNS/TLS/redirect/proxy policies remain unchanged.

Federation and OIDC package race tests and vet passed. Independent standards and specification/security reviews returned CLEAN for both fixes. Updated exact-head hosted CI remains required before merge.
