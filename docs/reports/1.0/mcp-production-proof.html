Defect found and fixed

The existing public smoke checker rejected a healthy actual server because its handwritten fixture omitted the modern SDK transport envelope: approved public server information, resultType, and static cache fields. The fix validates those exact fields before retaining all closed discovery/catalog/data/error checks. Unknown metadata, extra server information, incomplete results, negative TTL and private cache scope are rejected. The new TestPublicProfileAcceptsActualProductionHandler uses the actual production registry and SDK handler; it fails against the original checker source and passes after the fix. Normal and race checks passed locally. The repaired checker also passed against both actual application processes with committed revocation.

Independent R1 review found duplicate JSON members could hide an extra fact when a decoder kept only the last member. The checker now reuses the existing definitions.RejectDuplicateMembers before full RPC and standalone profile decoding. Raw wire regressions cover duplicate metadata, server information, nested description and result members. Normal/race tests, vet, and the rebuilt checker replay against both real processes passed after this fix. Independent R2 returned CLEAN and reran all 14 checker tests successfully.

Excluded invalid endpoint attempt

The first disposable ingress allocation timed out. A scratch parser incorrectly selected the Cloudflare API URL from the error log as the ingress URL. An SDK discovery request carrying one synthetic read-scoped fixture bearer reached that invalid API endpoint and received HTTP 405. This is an invalid probe and is excluded from every passing claim. The synthetic bearer was immediately revoked through the application service and replaced. No user credential, real tenant data, provider API key or production root authority was involved. Endpoint and credential values are deliberately absent from this report.

A second, bounded attempt accepted only a successfully allocated single-label quick-tunnel hostname from the success banner, explicitly excluding the API endpoint. The connector registered briefly, then exited because its outbound region2 TCP/UDP 7844 precheck failed. An unauthenticated exact-route HTTPS probe returned 530. That failed preflight prevented switching the application's origin or sending the replacement bearer. No further network retry was attempted. Public ingress success remains unverified.
