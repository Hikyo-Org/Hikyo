Implementation in review. API parity checks passed (100 tests), full web unit suite passed (677 tests across 83 files), and all six embedded desktop/mobile browser flows passed with dark/light axe and explicit overflow checks. Independent Standards review is CLEAN after strict numeric file-input validation; its 11 focused tests and TypeScript check passed.

Why these belong in 1.0

A browser-only self-hosting operator must be able to export and reconcile configuration definitions, inspect the exact impact before publishing, and see what their instance exposes to connected peers. Direct key editing cannot replace an immutable bundle plan; tenant lists cannot replace the instance-scoped directory identity. The previous parity registry claimed these were equivalent without those outcomes.

Defects found by running the embedded app

Observed failure Cause Fix and proof
Creating a valid additive plan returned 201, but the browser could not render it. The service returned a nil reveal-required slice; JSON serialized null even though the OpenAPI contract requires an array. The existing nonNil wire helper now normalizes all required definition-diff/plan lists. A contract fixture deliberately returns nil so the real regression cannot hide behind preallocated empty test arrays.
After planning, deleting an otherwise empty project returned 409 permanently for applied plans. definitions_plans retained a non-cascading project foreign key, and project deletion removed only its schema counter. Applied plans never expire. Authorized project deletion now explicitly removes its own plan ledger inside the same transaction and proof-bound tenant chain. Audit stays permanent. Both engines prove unapplied/applied cleanup, nonempty-project rollback, foreign actor/org refusal, and retained plan plus project-deletion audit.

Deletion decision: A: explicitly remove project-owned plans with the authorized project transaction; B: change the FK to blanket cascade; C: leave permanent deletion refusal. Chose A. Plan immutability and provenance retention govern the live project and scheduled GC; explicit project destruction ends its operational ledger. The independent audit remains durable. No migration, cascade authorization change, standalone purge operation, or audit deletion.

Final browser evidence and review fix

The final real embedded browser replay passed all six focused flows in 3.1 minutes. Mobile inspection found native file-input intrinsic sizing could overflow the dialog; the final layout constrains grid children and the file input, and tests now assert zero horizontal overflow. The recorded plan shows its digest and apply action within the mobile viewport.

Independent review found generated bigint response coercion accepted malformed file numbers such as booleans and numeric strings. File-input schemas now require integer JSON numbers before conversion, including direct and union min/max and base_revision. Arrays, objects, null, fractions, strings and booleans refuse before any API request. Response schemas remain unchanged. Review verification: CLEAN.
