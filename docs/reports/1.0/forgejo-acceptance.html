Defects found and fixed

Both deployment-provider factories create a fresh HTTP transport per module lease. Their Forget callbacks cleared credentials but retained idle sockets indefinitely. New real TLS regressions failed on both clients before the fix. Forget now closes its private idle connections, preserving bearer cleanup and GitHub release-once credential-state cleanup. Both complete provider packages pass ordinary and race tests. This also repairs a resource leak relevant to long-running self-hosted deployments.

The canonical external harness opened SQLite directly, and every raw crash-injection/observation query used SQLite handles. Setting HIKYO_TEST_POSTGRES_DSN could not exercise PostgreSQL. The test now runs named sqlite/postgres subtests with existing datastore openers, engine-neutral numbered parameters, and driver-specific execution/scan helpers. Every existing lifecycle assertion is preserved. The external fixture also now scrubs with a bounded live cleanup context because Go cancels t.Context before cleanup, and releases its client afterward. Final real-provider replay still passes both engines and leaves zero provider secret/variable rows.
