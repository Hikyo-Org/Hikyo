# PR #1012: Optional Graphify navigation

PR: <https://github.com/Hikyo-Org/Hikyo/pull/1012>

## Behavior

Agents use `rg`, `rg --files`, and focused source reads by default. Graphify
remains available for explicit requests and scoped relationship or impact
exploration. An ordinary source read or code edit does not require a graph
query, bootstrap, or refresh.

[AGENTS.md](../../AGENTS.md#graphify) owns the policy. [CLAUDE.md](../../CLAUDE.md)
points to that file instead of duplicating Graphify rules. The
[graph README](../../graphify-out/README.md) describes optional bootstrap and T3
worktree setup while preserving the canonical-main seed/cache workflow.

A local retrieval comparison motivated the change. Its raw benchmark artifacts
are not included in this PR; this is not a reproducible repository benchmark or
a claim that Graphify has no value for other workloads.

## Scope and boundaries

Only agent guidance, the graph README, and this handoff change. Application
code, generated graphs, hook configuration, and external T3 project settings
are unchanged. Existing Claude/OpenCode hooks may still emit Graphify reminders.
The README describes leaving automatic worktree graph setup disabled when only
source search is wanted; it does not alter an existing T3 installation.

Machine-local cross-project guidance is outside this PR.
