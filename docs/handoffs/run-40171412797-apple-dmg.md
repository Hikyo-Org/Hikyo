# Nightly Apple DMG contention recovery

## Incident

[Nightly run 40171412797, attempt 1](https://github.com/Hikyo-Org/Hikyo/actions/runs/40171412797/attempts/1)
failed at `apple-sign` on commit
`059902e8ca29ca2d41f7767d0d65a49d9211826f`.
All input checksums and Developer ID setup passed before creation of the first
HFS+ UDZO image failed with `hdiutil: create failed - Resource busy` and exit
code 1. Notarization was skipped. The existing second attempt passed signing
and notarization on the same commit. The holding process is unknown; this is
evidence of transient contention, not proof that a particular service caused it.

## Repair

The signing helper disables Spotlight index creation and allows at most three
image creation attempts per architecture. It retries only when the complete
stderr matches the observed busy diagnostic, removes partial images, and waits
two seconds before retrying. Other errors and mixed diagnostics fail immediately.
Terminal failures retain their status and diagnostics. Existing signature,
architecture, checksum, Keychain cleanup and staged artifact promotion checks
remain enforced. Workflow deadlines and security services are unchanged.

The shell fixtures cover independent recovery for both architectures, persistent
contention, second-architecture exhaustion, permission failures, misleading busy
text, prefixed diagnostics and mixed errors. They assert retry/pause counts,
unchanged original files, no partial image promotion or notarization on failure,
and cleanup. The fixture uses the observed create exit status and mocks pauses.

## Validation

Run from the repository root:

```sh
FAST_FEEDBACK_BASE=HEAD scripts/ci/fast-feedback.sh --working-tree --plan
FAST_FEEDBACK_BASE=HEAD scripts/ci/fast-feedback.sh --working-tree
sh -n scripts/release/sign-apple-artifacts.sh scripts/release/sign-apple-artifacts_test.sh
go test -p 2 -parallel 2 ./scripts/ci -run 'Test(Apple|Nightly.*(Signing|Transfer|Notarization|Publication)|HomebrewNightlyPublisherFixtures)' -count=1
git diff --check
```

These checks passed locally. The original implementation failed the added retry
expectations before the repair. Native macOS smokes of the modified helper also
passed with small arm64 and x86_64 Mach-O fixtures, ad-hoc signing and mocked
Keychain operations: both images passed UDIF verification, mounted executable
bytes matched their signed tarballs, permissions and architectures were correct,
and strict signatures passed. The arm64 fixture executed successfully.

An alternative using `makehybrid -hfs` and conversion was rejected after its
mounted payload failed strict signing verification due to added Finder metadata.

The local smoke is not Developer ID or notarization acceptance. Hosted execution
of the modified signing helper remains separate from PR CI and merge proof.
Release publication and production deployment are outside this repair's scope.
