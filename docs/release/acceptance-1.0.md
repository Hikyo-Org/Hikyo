## Evidence rules

INTERNAL-PASS means the mapped implemented acceptance suites and required internal deployment/resource checks passed for the tested candidate, reconciled to the identical merged tree. It does not certify official signing, public artifact availability, live external providers or an immutable freeze. Those remaining obligations have separate statuses. POST-1.0 remains the accepted deferred scope. No row is passed solely because a test exists.

Ordinary Go jobs are non-verbose: selected-suite execution plus inspected CI-fatal missing-PostgreSQL guards supports engine coverage, not invented named-case or per-test skip counts. Dedicated client/provider runs are evaluated separately. The regular race planner excludes isolation; the additional complete isolation race package passed at f31 as recorded below.

[Source reconciliation](../reports/1.0/evidence/acceptance-refresh-2026-09-05/source-reconciliation-f31-4394.json) proves f31-to 4394 changes only six CI/report files. Go runtime, Go tests and browser inputs are identical; CI fixtures are not. f31 Forgejo/full-isolation-race proof identities remain unchanged and support those unchanged workloads. Source equality does not imply binary-byte equality because embedded version/commit metadata may differ. New binary/archive hashes must be measured independently.
