It documents Google's web client and exact callback requirements, the accepted third-party-email assertion limitation, and local assurance for disclosure. The mail runbook distinguishes bootstrap variables from applied managed values, active settings from candidate revision tests, and configured status from actual SMTP submission and inbox delivery. It includes TLS and CIDR controls, shared five-per-hour test admission, one concurrent send, the 15-second deadline, 24-hour single-use verification, durable intent/outcome events and resend after an interrupted send. It preserves the managed configuration and restore fences.

Release notes follow the shipped migrations, rather than the synthesis's historical migration numbers. Migration 57 preserves sessions and closes disclosure reauthentication windows on both engines.
