Operator documentation

The social sign-in runbook covers tenant-GUID Entra issuers, one provider row and callback per tenant, ID-token optional claims, and strict JSON boolean email assertions. It documents Google's web client and exact callback requirements, the accepted third-party-email assertion limitation, and local assurance for disclosure. GitHub uses the supported GitHub.com OAuth App profile, pinned scope and PKCE, write-only secrets and explicit registration admission.

The mail runbook distinguishes bootstrap variables from applied managed values, active settings from candidate revision tests, and configured status from actual SMTP submission and inbox delivery. It includes TLS and CIDR controls, shared five-per-hour test admission, one concurrent send, the 15-second deadline, 24-hour single-use verification, durable intent/outcome events and resend after an interrupted send. It preserves the managed configuration and restore fences.

Release notes follow the shipped migrations, rather than the synthesis's historical migration numbers. Migration 57 preserves sessions and closes disclosure reauthentication windows on both engines. Migrations 57 and 58 clear in-flight OIDC transactions. Migration 44 already retired the old JIT policy; migration 58 performs no second fold or audit cleanup. Existing explicit identities remain, and admitting unknown identities needs an explicit policy.
