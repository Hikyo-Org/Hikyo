Private client secret lifetime remediation

2026-09-05. Author validation snapshot before private delivery. No advisory update or public report. Base: 33a213ca80bfff4ffb4a808cf916f209fd90138d

Confirmed baseline

A real QueryClient/TOTP hook regression failed after unmount: both the synthetic password input and otpauth display-once result remained in MutationCache. This test now requires an empty MutationCache even when global mutation defaults request retries and infinite retention.

Decisions

Use a typed, component-owned one-shot primitive with no TanStack mutation registration, result/variable state, offline queue or automatic replay. Keep only local status/error. Reset, unmount and explicit session retirement suppress late result/callback delivery. QueryClient-scoped lifetime counters and cleanup listeners contain no request or result payloads; multiple providers are isolated. AuthProvider calls retirement before clearing caches on replacement, logout, expiry and owner teardown. Existing workspace session-keyed subtree unmount and machine/lease mint boundary remain in place.

Submitted passwords, codes, credentials and value drafts are cleared at submit/settle. Display-once outputs remain only in their active surface until close/remask/session retirement. Refusal keeps the editable form and safe message; manual retry requires freshly entered plaintext. This intentionally updates the previous rejected-write test that expected plaintext retention. Matrix scanner/ceremony work stays in its active operation until the user decision completes, then submitted edits clear. The fill-all password field clears when transferred to edits, after settle and at session retirement. Imported plaintext clears when the import reaches its result step.

Existing plain async mint helpers remain uncached. Component state for connection/SCIM mint, invitation/reset, recovery/establishment and OIDC/dynamic provider credentials now shares the retirement boundary. Recovery and establishment requests use guarded local execution so dismissed surfaces cannot deliver late success. Disclosure ceremonies retain their existing task-identity guard and now clear code input. Active requests may still commit server-side after a surface closes; this is delivery suppression, not a claim of server rollback or JavaScript heap zeroization.

Future guard: all mutation-capable source modules are pinned by exact SHA-256. Imported aliases, MutationObserver and direct cache construction trigger review. New/changed modules fail the test until their input/result contracts are explicitly reviewed. This is deliberately broader than a fragile field-name heuristic. Review covers intended contract values; free-text metadata and public JWKS are not credential channels.
